## 2. 代码事实（区分事实与推断）

1. **运动 gate 缩放哪些分量**（事实）：`3. Tracker/trackers/track.py:223-255`。
   先保存更新前状态（231-233：`mean_prior`/`covariance_prior`/`predicted_box`），再做完整
   KF 更新（236-238）。门控 g=1（241-244）取 `mean_full`/`cov_full`；g=0（245-248）取
   `mean_prior`/`cov_prior`；中间值（249-255）对均值**全部 8 个分量**线性插值
   `[cx, cy, w, h, vx, vy, vw, vh]`（状态布局见 `agentguard/src/agentguard/motion/nsa_numpy.py:11`），
   协方差做凸组合（251-252），而写回历史/当前帧的 `effective_box` 是 `predicted_box` 与
   检测框的插值（255）。因此：位置、尺寸、速度、协方差都被缩放；当前帧框与 KF 均值是
   两个独立插值对象。Q/R 不参与（更新调用 NSA KF，见 `nsa_numpy.py:130`）。
2. **监督样本筛选**（事实）：钩子只包裹 `Track.update` 与 `Track.update_with_gates`
   （`tools/sportsmot_supervision_pilot.py:583-601`），即**只有匹配成功的事件**进入记录；
   无检测/失配帧不构成监督样本。D 组损失使用 `motion_gt_valid`（`_compute_motion_endpoints`，
   `pilot:692-700`），要求下一帧 warp 与该身份 GT 都存在。错配（检测的 GT 身份 ≠ 轨迹身份）
   不过滤，仍按轨迹身份计算端点与标签。
3. **GT 目标身份**（事实）：`target_gt_before = vote.resolve_before_current(...)`
   （`pilot:535`；实现 `agentguard/src/agentguard/data/identity_vote.py:20-42`），由**当前观测之前**
   的历史投票决定；当前检测的 GT 身份单独记录（`detection_gt_id`，`pilot:558`）并在之后
   加入投票（`pilot:536`）。所以监督目标是轨迹的原身份，不是当帧检测的身份。
4. **t+1 与缺帧**（事实）：端点直接用 `frame_id + 1`（`pilot:641`），没有"下一个可见帧"逻辑；
   下一帧 warp 缺失（`pilot:645`）或该身份 GT 缺失（`pilot:690`）时 `motion_gt_valid=False`，
   样本被运动损失屏蔽。视频帧索引本身连续，缺 GT 主要来自遮挡/标注缺口。
5. **缓存端点与在线路径**（事实）：replay 的 warp 从在线同一组 GMC 文件读取
   （`pilot:253-270`），summary 中 `warp_max_abs_error = 0.0`；KF 使用同一个
   `NSAKalmanFilter`；中间门控的框线性插值与真实状态路径的最大误差
   `kf_box_mid_error_max ≈ 4.5e-13`（c003/MOT20-02 均如此）。因此 g=0/g=1 端点与在线
   下一帧预测完全一致；中间 g 的框插值在一步内是精确的。
   *与在线路径的差别*：在线在中间 g 时同时插值均值与协方差，并另用 `effective_box`
   写当前帧；诊断的 A/B/C/D 是均值分量分解，不是在线中间 g 路径（见 §4）。

## 4. 位置修正 vs 速度修正（A/B/C/D）

定义（同一更新前状态，同一 warp，一步预测）：A=不更新；B=仅位置/尺寸取更新值；
C=仅速度取更新值；D=全更新。一步预测框只由均值决定（协方差只影响协方差），所以四者
协方差统一取 `cov_full` 不改变比较；四者都不是在线中间 g 路径。

## 5. 优先结论（有证据支持）

**门控在 SportsMOT 失效的首要原因是监督目标的边界解，而不是位置/速度分量设计缺陷。**
证据链：

1. 下一帧收益几乎完全由"先验误差 vs 检测误差"决定（八片段二维分位表单调，跨项目一致）；
2. SportsMOT 的先验误差是检测误差的 2–3 倍，全写入在 86–92% 的事件上更优，
   平均一步 DIoU 的最优解落在 g=1 边界（前次分析 L(0.9)=0.1331 > L(1)=0.1275）；
3. 真正该抑制的事件（错配、大检测误差、急转）确实被现有 GT DIoU 监督标成有害
   （错配有害率 44–56%，检测误差最高分位有害率 90–100%），但在 SportsMOT 只占 0–4.7%，
   在平均损失中被多数类淹没；
4. 位置/速度分解显示位置修正是主要收益来源，独立速度修正与位置冲突时净损失远大于收益；
   四路 oracle 相对全更新只有 +0.003–0.008 DIoU，分量拆分不是优先项。

因此优先做的是**监督形式的机制改动**：逐事件"哪个端点更优"的目标（软目标
sigmoid((DIoU1−DIoU0)/τ)）+ |DIoU1−DIoU0| margin 加权 + 少数类配平，替代对 g 的平均
DIoU 回归；在此之前先用强制门控（g=0/0.5/1/逐事件 oracle）在 SportsMOT val 上量一次
HOTA/AssA 的真实上限，若 oracle 增益 <0.1–0.2 pp 则停止。位置/速度拆分不作为优先方向。

## 6. 证据缺口

- 未测 HOTA（按约束不做在线验证）；所有收益均为一步 DIoU，不能直接换算成 HOTA。
- 当前帧检测误差只在当前帧该身份 GT 存在时可得；无 GT 的事件不进入该列。
- 四路反事实是一步均值分解，不是在线中间 g 路径；在线还插值协方差并用
  `effective_box` 写当前帧。一步框只依赖均值，故比较与协方差选择无关。
- 轨迹身份由历史投票解析（≥3 票、top≥0.75）；检测 GT=-1 计为未标注，错配按
  解析身份判定。
- 若要把"抑制有害更新"的收益归因到长期关联（而非一步框），现有数据（只有 t+1 端点）
  不足以回答，需要多步回放——本轮未做。
